\section{Problématique}
\label{sec:problematique}

Notre projet part d'une question simple :

\begin{quote}
\itshape Un modèle entraîné de zéro sur un jeu de données de taille limitée peut-il reconnaître assez bien les usagers de la route pour guider les décisions d'un véhicule simulé ?
\end{quote}

Pour y répondre, nous devrons aussi éclaircir trois points :

\begin{itemize}
  \item Parmi les modèles classiques, lequel obtient le meilleur score ? Et un CNN entraîné de zéro fait-il vraiment mieux sur les mêmes données ?
  \item Quelles classes sont les plus difficiles à reconnaître, et qu'est-ce qui l'explique ?
  \item Que se passe-t-il concrètement pour le véhicule quand le modèle se trompe, notamment lorsqu'il ne reconnaît pas une personne ?
\end{itemize}
