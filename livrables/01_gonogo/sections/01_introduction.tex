\section{Introduction}
\label{sec:introduction}

Un véhicule autonome doit identifier ce qui l'entoure pour décider : s'arrêter devant un piéton n'est pas la même réaction que contourner un camion. Ce projet PACTE de 4\textsuperscript{e} année à HESTIM traite cette étape de classification par le Machine Learning.

Le sujet impose de choisir un jeu de données, de comparer plusieurs modèles, d'analyser les classes difficiles et de tester le modèle final sur de nouvelles images. Ce dossier présente notre cadrage pour la décision de Go/noGo, qui compte pour 15~\% de la note finale.
