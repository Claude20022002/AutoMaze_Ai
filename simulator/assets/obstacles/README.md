# Illustrations des obstacles

Ces images servent **uniquement à l'affichage** dans la vue conducteur et sur les cartes. Elles ne sont jamais
données au classifieur : le modèle classe les recadrages du jeu de test (`data/crops/test/`), ou les images
de remplacement de l'équipe B tant que ces recadrages n'existent pas.
